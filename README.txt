iCloudNet website files for GitHub Pages

Files:
- index.html (main website page)
- styles.css (website design)
- script.js (menu and enquiry form behavior)

Before launch:
1. Replace hello@icloudnet.in in index.html with your real monitored business email.
2. Create a Formspree form and replace YOUR_FORM_ID in index.html with the form ID they provide.
3. Publish these files using GitHub Pages.

This folder is the static website version. Do not upload the earlier Node.js server project for GitHub Pages.
